# SQL
## <ins> Kaylee's SQL Portfolio <ins>

### Welcome to my SQL portfolio! This code repository contains examples of SQL I've written. Feel free to take a look and reach out if you have any questions.

#### Customer Analytics:
#### These queries provide visibility into monthly order trends, product demand and popularity, customer purchasing behavior, revenue generation by product and location, and pricing insights. 

#### Climate Conference Project:
#### This was a simulated scenario for a conference where I was able to provide insights on speaker participation, accommodations, event attendance, feedback assignments, and networking activities.

#### Fortune 500 Analysis:
#### These queries analyze a simulated Fortune 500 company data set to evaluate employee benefits, workforce characteristics, company size, and industry-level financial performance. The analysis focuses on identifying organizations that offer strong employee support programs while also examining trends across industries.

#### Chinook Project: 
#### This project queries the database to find insights into business performance, customer demographics, sales effectiveness, and product offerings. 

#### Shopify Data:
#### In this project I used data downloaded from Kaggle to analyze the data from Shopify on their revenue performance, product profitability, customer purchasing behavior, returns, discounts, and sales channel effectiveness.

#### Spotify Data: 
#### These queries analyze Spotify track data to understand artist popularity, song characteristics, and listening trends. This analysis focuses on identifying top-performing artists and songs while examining key song attributes such as danceability, energy, and track duration.

#### Superstore Database:
#### This project provides insight for a simulated superstore into product pricing, customer ratings, and inventory levels within the store to better understand product value, category pricing trends, and stock availability.
